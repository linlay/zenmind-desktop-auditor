WebApp 页内 WebClient

Lab 提供页面聊天容器及本实例 Chat ID；Desktop 在对应区域加载可信 WebClient 正式聊天时间线（复用 ConnectedConversationStage 及原样式），原输入区仍负责请求。没有独立弹窗，也不需要开启公网 embed、配置白名单或提供展示 token。

页面通过 desktop.chat.embed 同步区域、挂载身份和修订；宿主复验应用与 Chat 归属，使用独立 webapp-chat Surface 和 Frame Port/Broker 观察。滚动/缩放同步与裁剪属于宿主展示逻辑，销毁只解除观察，不中断 Run。
