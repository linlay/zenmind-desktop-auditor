# 无客户端凭据迁移

1. 独立服务私有目录接收原企业 OIDC 配置，使用 0700 目录、0600 文件（Windows 当前用户 ACL）。不回显凭据。
2. Auth Lab 删除旧 oidc 配置、模板和直接 OIDC 客户端实现。旧配置备份只能存独立服务私有目录，不留应用目录。运行中旧进程须退出以清除内存中的配置。
3. 应用配置只增加 broker.origin 和公开 appId，保留 Desktop 公钥验签和业务配置。服务登记精确 callback。
4. 企业管理员需登记独立服务的固定 /api/enterprise/callback；启动健康不等于企业白名单或真实授权码闭环验收。
5. ZIP 由用户更新；不自动导入 Desktop。本机 4192 测试入口可单独替换，不重启 Desktop。

旧作者身份不按邮箱自动迁移；新身份对共享便签的查看遵守原规则。远程用户必须用可达的 HTTPS callback，不把手机的 127.0.0.1 当作电脑服务。
