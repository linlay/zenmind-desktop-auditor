# DAG Lab 验收清单

## 自动回归

构建后运行 `npm test`，验证 DAG 校验、真实上下游数据、串行调度、业务失败、取消、执行快照、持久化与重启中断、后端访问边界以及最终 ZIP。`npm run smoke -- --desktop-repo ...` 使用该 checkout 的 Electron、隔离 profile、真实 Gateway 和正式生成 SDK，模型结果由本机受控测试服务提供。受控响应只证明应用流程与传输，不证明真实账号、模型或系统弹窗成功。

## Desktop 手动验收（macOS / Windows 分别执行）

- 导入 ZIP，选择具备 result_submit 的 Native Agent，执行需求评审模板。确认 3 个智能体节点使用各自提示词和上游结果，最终输出可展开。
- 打开智能体节点对话历史，确认真实 Chat ID 与节点匹配。独立窗口或后台应用无法打开时显示宿主错误。
- 智能体未配置、Agent 不支持 execute、业务 failure、服务断开时显示真实错误，不生成成功结果、不重试模型。
- 运行较长任务后取消，确认当前 execute 被中断，未开始节点跳过；已经发生的操作不声称回滚。
- 运行期间刷新、隐藏或切换应用，再回来查看进度，不创建第二次运行。停止或重启应用后旧未完成记录显示中断，不自动恢复模型执行。
- 添加节点、拖动、连线、编辑依赖，验证自环、环、重复边、断开的节点不能执行；删除节点同时移除关联连线。
- 修改节点参数必须应用，再保存；运行快照不受后续草稿编辑影响。检查已保存状态、两窗口 revision 冲突及导入失败后旧草稿保留。
- JSON 导出再导入，校验标签、提示词、Schema、位置和边一致；恶意 HTML 标签只作为文字显示。无论模板还是导入都不自动执行。
- 完成运行后重启，确认流程和历史保留；导出完整运行结果，删除旧记录，升级同 ID ZIP 后数据保留。
- 在浅深色、宽屏、窄屏和触摸场景检查画布、配置栏、键盘操作及缩放。macOS 使用 Cmd+S，Windows 使用 Ctrl+S 保存。

## 无模型预览

运行 `npm run dev`，加载数据汇总模板，可在普通浏览器完成真实本地数据流程。需求评审模板的运行按钮明确不可用；不注入模拟 SDK、不生成假的智能体结果。预览与安装实例的数据目录互相独立。
