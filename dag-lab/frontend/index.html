连接任务，逐步执行。
  1. 选择模板，或添加输入、智能体、汇总和输出节点。
  2. 点击节点编辑参数，点击“应用修改”。通过端口或上游依赖连接节点。
  3. 在连接面板填写 Platform 地址及访问令牌，选择默认 Agent；每个节点也可独立选择 Agent。执行 Agent 需要 result_submit 工具。
  4. 检查并保存流程，点击运行。选中运行节点查看输入来源与实际结果，可打开真实对话历史。
运行使用保存时的快照；刷新页面会重新连接后台运行。取消不会回滚已执行操作。应用停止或后端重启后，未完成记录标记为中断，不自动重发。
使用浏览器访问本机应用地址，即可编辑、运行智能体 DAG 并查看 Platform 对话。Desktop 仅托管应用，网页不加载 Desktop Bridge。令牌只存在后端内存，应用重启或令牌到期后需要重新连接；也可由启动环境注入 DAG_LAB_PLATFORM_URL/TOKEN。
