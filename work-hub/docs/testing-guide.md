# 验收指南

## 自动验证

`npm test` 覆盖业务持久化、引用约束、版本冲突、日期/字段/邮箱校验、筛选排序分页、指标一致性、存储失败回滚、并发创建、级联删除确认冲突，以及真实本机 HTTP 的来源限制、Platform 请求与交卷、错误引用拒绝、取消上游与凭据不落盘。

先 build 后运行 smoke。隔离 Electron 页面验收加载安装包中的前后端，验证：

1. 工作概览真实指标与两类 SVG 图表。
2. 项目、任务、成员在 UI 中创建、编辑、详情、删除。
3. 备注持久化和 HTML 转义，任务状态与图表更新。
4. 搜索、分页、全局搜索导航、取消删除与级联删除。
5. 实际 HTTP Platform 测试服务的分析快照、报告展示、建议预填后确认创建。
6. 取消分析确实关闭上游请求，重载保留数据，无 Desktop Gateway 请求。
7. 1520、1050、390 宽度的页面截图及外层溢出检查。

输出为临时目录 `work-hub-browser-*`，包括截图与 smoke.json。测试响应明确属于隔离 fixture，不是线上模型输出。

## 人工真实环境

- 浏览器打开本机 URL，新增一个项目和若干任务，在列表筛选、详情、图表中核对；重启应用后确认仍存在。
- 两个页面同时编辑同一任务，后保存的旧版本应提示冲突。
- 删除带任务项目时取消，检查任务还在；确认删除时核对提示数量和实际删除范围。
- CSV 导出筛选结果，JSON 导出业务数据；检查中文、数字与公式前缀安全转义。
- 连接真实 Platform；401 时重新输入凭据。选择支持结构化 result_submit 的 Agent，按全局和单项目分别分析，核对报告引用、来源记录数、智能建议与实际快照。
- 确认建议按钮只预填表单，取消表单不会创建任务；保存后从任务详情验证。
- 验证 Platform 对话历史、运行取消、服务不可达、认证过期和交卷失败；不得以预置报告替代失败。
- 通过 Desktop 导入 ZIP、启动、从普通浏览器访问分配地址；关闭、重启验证生命周期和数据目录。
- Windows 与 macOS 各执行构建、Desktop 导入、普通浏览器访问、持久化、取消、中文路径；当前自动截图证据来自 macOS，未替代 Windows 实机验收。
